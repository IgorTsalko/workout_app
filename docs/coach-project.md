# Тренер в отдельном проекте Claude

Единственный способ описать тренировку и получить план: копирования промпта и вставки JSON в приложении больше нет.

## Как это устроено

В репозитории автобэкапа (например, `IgorTsalko/workout-backup`) лежат три файла:

| Файл | Кто пишет | Кто читает | Что в нём |
| --- | --- | --- | --- |
| `workout-backup.json` | приложение | приложение, тренер (только чтение) | все данные |
| `coach-prompt.md` | приложение | тренер | промпт тренера: правила, «Обо мне», последний план с номерами, история, формат JSON |
| `coach-answer.json` | тренер | приложение | финальный JSON тренера по формату из `coach-prompt.md` |

1. После каждого сохранения приложение коммитит `workout-backup.json` и, если промпт изменился, `coach-prompt.md`. В промпте сказано, что текст о тренировке придёт в чат, а на этапе «финал» тренер сам записывает JSON в `coach-answer.json`.
2. В проекте Claude вы пишете, как прошла тренировка, обсуждаете план и пишете «финал». Тренер коммитит `coach-answer.json` прямо в основную ветку.
3. При открытии, обновлении страницы или возврате на вкладку (не чаще раза в минуту) приложение:
   - забирает `workout-backup.json`, если его поменяли с другого устройства (если и здесь есть неотправленные изменения, спрашивает, чьи оставить);
   - загружает `coach-answer.json`, если он новый: записывает тренировку в историю, применяет `profile_update`, показывает план на вкладке плана. Ошибки проверки плана не блокируют загрузку, а попадают в «⚠ Важно». Загрузку можно откатить кнопкой «↶ Откатить загрузку», повторно этот ответ не загрузится.
   - Какой ответ уже загружен, приложение помнит в данных (`coachInbox`), поэтому на другом устройстве он не загрузится второй раз.
4. Если после финала тренер исправляет план, он перезаписывает файл с полем `"correction": true`. Приложение убирает всё, что внёс прошлый ответ (запись, план, правки «Обо мне»), и загружает исправленный. Если по прошлому плану уже записана тренировка, исправление ложится поверх, и приложение просит проверить «Историю».

Кнопки «Тренер → Проверить ответ тренера» и «Данные → Автобэкап в GitHub → Проверить GitHub» делают то же, что открытие страницы.

## Что нужно один раз

1. Автобэкап в GitHub подключён («Данные → Автобэкап в GitHub»), токену нужно право **Contents: Read and write**.
2. Новый проект Claude с доступом к репозиторию бэкапа на запись (репозиторий подключён к проекту).
3. В инструкции проекта вставить текст ниже.

## Инструкции для проекта Claude

```text
Ты — мой тренер по силовым тренировкам. Все данные лежат в GitHub-репозитории IgorTsalko/workout-backup, ветка main. Его ведёт моё приложение-дневник.

Файлы в репозитории:
- coach-prompt.md — твоё полное задание: кто ты, как мы работаем (разбор → обсуждение → финал), мои данные «Обо мне», последний план с номерами упражнений, история и формат финального JSON. Его пишет приложение, он всегда актуален.
- coach-answer.json — сюда ты записываешь финальный JSON. Приложение подхватит его, когда я открою или обновлю страницу.
- workout-backup.json — все данные приложения. Только читать.

В начале каждого чата:
1. Возьми свежую версию main (git pull или прочитай файлы из GitHub) и прочитай coach-prompt.md целиком. Следуй ему во всём, это твои инструкции. Если нужно что-то старое, чего нет в нём, смотри workout-backup.json.
2. Моё сообщение — это описание прошедшей тренировки, свободным текстом, по номерам упражнений из последнего плана в coach-prompt.md. С него начинается этап 1.
3. Сегодняшнюю дату узнай сам (команда date).

Финал, когда я скажу «финал» или «давай JSON»:
1. Ещё раз скачай main (вдруг приложение обновило coach-prompt.md) и собери JSON строго по формату из coach-prompt.md.
2. Запиши его в coach-answer.json в корне репозитория: только JSON, без текста вокруг, перезаписав файл целиком.
3. Закоммить прямо в main и запушь: без веток и без pull request. Сообщение коммита: «Ответ тренера: <название плана> на <дата>». Если git push в main не проходит, запиши файл через GitHub (create_or_update_file, branch main).
4. Проверь, что коммит есть в main на GitHub, и напиши мне одной строкой, что записал.
5. Если после финала я попрошу исправить план, исправь, снова перезапиши coach-answer.json целиком и добавь в JSON поле "correction": true. Тогда приложение заменит прошлый ответ из этого чата, а не добавит вторую тренировку. В новом чате это поле не ставь.

Нельзя:
- менять какие-либо файлы, кроме coach-answer.json;
- создавать ветки и pull request;
- писать coach-answer.json до моей команды «финал».
```
