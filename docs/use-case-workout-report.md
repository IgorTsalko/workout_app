# Use case: записать тренировку одним сообщением через Claude

## Задача

Не заполнять форму по каждому подходу. После тренировки описать её своими словами, без заданного формата, и получить готовую запись в истории.

Приложение не обращается к AI напрямую. Обмен идёт через копирование: приложение выгружает промпт тренера, в чате Claude идёт обсуждение, итоговый JSON вставляется обратно.

## Порядок действий

1. **Сегодня.** Тренируешься по плану. У каждого пункта есть номер: разминка — 1, дальше упражнения 2, 3…, части суперсета — 4А, 4Б, заминка — последний номер. Те же номера на картинке PNG и в тексте с чекбоксами.
2. **Тренер → Шаг 1.** После тренировки пишешь в поле «Как прошла тренировка», как всё прошло. Формат любой: номера, названия, цифры, ощущения, самочувствие, сон, вес тела, пожелания и вопросы к тренеру прямо по ходу текста («4А — правильно ли я делаю, если тянет поясницу?»). Если тренировку пропустил или заболел, пишешь и это. Под полем можно раскрыть номера упражнений текущего плана. Текст сохраняется сам и сразу попадает в промпт.
3. **Скопировать промпт тренера.** На том же шаге. В промпт попадают план с номерами, твой текст как есть, порядок работы и правила разбора.
4. **Обсуждение с тренером (Шаг 2).** Вставляешь промпт в чат. Первый ответ — без JSON: разбор тренировки, ответы на каждый вопрос из текста, разбор пожеланий, план следующей тренировки с объяснением каждого упражнения и баланс мышечных групп за неделю. Дальше уточняешь и споришь сколько нужно. Когда согласен, пишешь «финал» — тренер возвращает один блок ```json, в котором:
   - `completed_workout` — разобранная тренировка с учётом уточнений из обсуждения;
   - `answers` — вопросы из текста и итоговые ответы;
   - `summary`, `recommendation`, `warnings`, `wishes_review`, `next_workout` — итог и новый план.
5. **Тренер → Шаг 3.** Вставляешь финальный ответ целиком и жмёшь «Загрузить ответ». Приложение проверяет план (одно упражнение дважды, в том числе в разминке), записывает тренировку в историю и загружает новый план. Ответы на вопросы показаны на «Сегодня» в блоке «❓ Ответы тренера». Поле описания очищается.
6. **Проверить.** Если Claude что-то додумал (например, про упражнение ничего не было сказано и он посчитал его по плану), приложение открывает «Историю», и в записи есть блок «Как Claude понял описание — проверьте». Ошибку можно поправить кнопкой «Редактировать».

Всё делается на одной вкладке «Тренер», отдельной вкладки для записи нет. Ручная форма осталась только для правки уже сохранённых записей.

## Формат `completed_workout`

```json
{
  "date": "2026-10-07",
  "status": "done",
  "exercises": [
    { "tag": "2", "as_planned": true, "rpe": 85 },
    { "tag": "3", "rpe": 95, "notes": "последний подход тяжело",
      "sets": [ { "weight": 80, "reps": 6 }, { "weight": 80, "reps": 6 }, { "weight": 80, "reps": 5 } ] },
    { "tag": "4А", "skipped": true, "notes": "не успел" },
    { "tag": null, "name": "Шраги с гантелями стоя", "sets": [ { "weight": 30, "reps": 15 } ] }
  ],
  "wellbeing": 4, "effort": 85, "duration": 65, "sleep": 7, "bodyweight": 76.4,
  "notes": "", "extras": "", "reason": "",
  "wishes": "больше трапеции", "insist": true,
  "assumptions": ["5: в тексте не упомянуто, считаю по плану"]
}
```

| Поле | Смысл |
|---|---|
| `tag` | Номер из плана. Название и плановые цифры приложение берёт из плана по номеру. Разминка и заминка в `exercises` не попадают: подходов у них нет, замечания о них идут в `notes`. Номер целого суперсета («4») разворачивается во все его части. Латинские буквы (`4a`, `4B`) тоже понимаются. |
| `as_planned` | Сделано как в плане: подходы копирует приложение, Claude их не переписывает. |
| `sets` | Фактические подходы, если что-то отличалось от плана. |
| `skipped` | Упражнение не делал: в истории подходы плана помечаются как невыполненные. |
| `tag: null` + `name` | Упражнение не из плана. |
| `status` | `done`, `skipped` (пропуск) или `sick` (болезнь); для двух последних — `reason`, без упражнений. |
| `assumptions` | Что Claude додумал или понял двояко. Показывается в «Истории». |

Чего нет в тексте, то `null`. Пожелания из текста попадают в запись (`wishes`, `insist`) и разбираются в `wishes_review` того же ответа.

## Варианты

- **Ответ без `completed_workout`** (описания не было): загружается только план, как раньше.
- **Ответ только с `completed_workout`** (без `next_workout`): тренировка записывается, план не меняется.
- **Тот же ответ вставлен повторно**: приложение спросит, загружать ли его ещё раз.
